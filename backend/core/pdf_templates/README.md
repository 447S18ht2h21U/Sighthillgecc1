# Approved interactive PDF templates

Owner-supplied interactive template PDFs are private deployment inputs, excluded from this public repository. Configure their directory with GECC_PDF_TEMPLATE_DIR. Original form pages, company logo, Maryland artwork, and native signature fields are retained. The manifest records the template hashes and field inventory. Approve a replacement template hash through a reviewed code change; generated documents record its exact hash.

Document preparation populates approved commercial values, preserves unsigned customer and GECC signature fields, and adds complete approved project detail pages. Preparation copies carry an unsigned watermark. Completion dates and signing dates remain unset. No signing order, cancellation deadline, work completion, lender funding, or payment receipt is asserted by generating a preparation copy.
